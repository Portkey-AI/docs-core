looot is a **hosted remote MCP server** that fronts thousands of data-provider operations behind one account and one prepaid balance. Agents can search the catalog, see the price before a call runs, and pay per successful call.

## When should you use it?

Use the looot MCP server when you want an agent to:

* Find or verify work emails and phone numbers.
* Search companies and people.
* Run web, Google, news, or LinkedIn lookups.
* Fetch web page content or local business data.
* Cap spend with a visible per-call price instead of many provider keys.

## Endpoints

* **Transport**: Streamable HTTP
* **URL**: `https://api.looot.ai/mcp`
* **Authentication**: OAuth 2.1 with PKCE and dynamic client registration (browser sign-in), or a bearer token in the `Authorization` header
* **Discovery**: `https://api.looot.ai/.well-known/oauth-protected-resource` and `https://api.looot.ai/.well-known/oauth-authorization-server`

## Tools

The catalog covers email find/verify, company enrichment, SEO and SERP data, social profiles, web scraping, and related data APIs. See [docs.looot.ai](https://docs.looot.ai) for the current tool list and pricing.
