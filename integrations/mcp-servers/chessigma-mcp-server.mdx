Chessigma is a **hosted remote MCP server** for chess education and analysis helpers. It does not run an engine or return best-move evaluations; game-review links open analysis in the browser.

## When should you use it?

Use the Chessigma MCP server when you want an agent to:

* Look up opening names and guides.
* Check legal moves from a FEN position.
* Extract facts from a PGN game.
* Open a browser game-review link.
* Fetch the daily chess puzzle.
* Estimate Elo from game data.

## Endpoints

* **Transport**: Streamable HTTP
* **URL**: `https://www.chessigma.com/api/mcp`
* **Authentication**: None required

## Tools

Capabilities include opening guides and names, FEN and PGN checks, daily puzzle retrieval, Elo estimates, and game-review links. See the [Chessigma MCP docs](https://www.chessigma.com/developers/mcp) for the full tool list and connection examples.

## Notes

* No account or API key is required.
* Setup repository and public descriptor: [mehdi-bh/chessigma-mcp](https://github.com/mehdi-bh/chessigma-mcp).
* Official registry name: `com.chessigma/chessigma`.
