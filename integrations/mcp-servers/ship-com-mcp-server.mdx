Ship.com's MCP server is **centrally hosted**. It uses the same account permissions, balances, and safety checks as the Ship.com web app.

## When should you use it?

Use the Ship.com MCP server when you want an agent to:

* Check and create shipping orders.
* Compare USPS and UPS rates.
* Buy or void shipping labels.
* Schedule pickups.
* Manage customers and send customer email.
* Retrieve shipping reports.

## Endpoints

* **Transport**: Streamable HTTP
* **URL**: `https://app.ship.com/mcp`
* **Authentication**: Ship.com access token or supported OAuth sign-in

## Tools

Capabilities include orders, rate comparison, labels, pickups, customers, email, and shipping reports. See the [Ship.com MCP docs](https://www.ship.com/api/mcp) for the full tool reference and setup examples.
