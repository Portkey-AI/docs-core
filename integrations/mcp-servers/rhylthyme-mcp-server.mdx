Rhylthyme is a **hosted remote MCP server** for scheduling any real-time, multi-track process as a program: parallel tracks of timed steps with dependencies and resource limits. It validates programs, analyzes schedules (makespan, critical path, conflicts), imports recipes and protocols from the web, and returns a shareable live timeline.

## When should you use it?

Use the Rhylthyme MCP server when you want an agent to:

* Validate or analyze a multi-track timed program.
* Import a recipe or protocol from the web into a Rhylthyme program.
* Preview or visualize a schedule and critical path.
* Search public recipes or load a public run.
* Optionally log in to save and load personal programs and runs.

## Endpoints

* **Transport**: Streamable HTTP
* **URL**: `https://mcp.rhylthyme.com/mcp`
* **Vertical endpoints** (same tools, domain-specific guidance): `/kitchen/mcp`, `/lab/mcp`, `/events/mcp`, `/gym/mcp`
* **Authentication**: None for public tools. A `login` tool issues a token for optional personal-library tools.

## Tools

Public tools include `validate_program`, `analyze_schedule`, `visualize_schedule`, `preview_timeline`, `review_program`, `import_from_source`, `import_text`, `create_environment`, `search_public_recipes`, `load_public_recipe`, `list_public_runs`, and `get_renderer_source`. After `login`, personal-library tools cover listing, loading, and saving programs and runs. See the [Rhylthyme docs](https://docs.rhylthyme.com) for the full tool list, resources, and the `plan_schedule` prompt.

## Notes

* No account or API key is required for the public tools.
* Setup repository: [rhylthyme/rhylthyme-mcp](https://github.com/rhylthyme/rhylthyme-mcp) (Apache-2.0).
* Official registry name: `com.rhylthyme/rhylthyme`.
* Website: [rhylthyme.com](https://www.rhylthyme.com).
