## Overview

Audit Logs in the AI Gateway provide a comprehensive record of all administrative activities across your organisation. These logs capture detailed information about who performed what actions, on which resources, and when those actions occurred. This level of visibility is crucial for security monitoring, compliance requirements, and troubleshooting operational issues.

## Key Benefits

- **Enhanced Security**: Track all changes to your organisation's resources and configurations
- **Compliance Support**: Maintain detailed records to help meet regulatory requirements
- **Operational Visibility**: Understand who is making changes and when
- **Troubleshooting**: Investigate issues by reviewing recent configuration changes
- **Accountability**: Ensure users are responsible for their actions within the platform

## View Audit Logs in Strata Cloud Manager

Audit events from the AI Gateway appear in the Strata Cloud Manager (SCM) **Log Viewer**.

1. In SCM, open **Log Viewer**.
2. From the log type drop-down, select **Common/Audit**.
3. In the search bar, enter `Log Source = 'airs_gw'` and click **Search**.
4. Use the time range selector to widen or narrow the period.

<Note>
    Audit logs are collected automatically across all workspaces. No additional configuration is needed.
</Note>

## Logged Information

Each audit log entry contains the following fields:

| Field | Description |
|-------|-------------|
| TSG ID | The tenant service group (TSG) the event belongs to |
| Log Source | Always `airs_gw` for AI Gateway events |
| Subtype | Always `api_activity` |
| Time Received | Date and time when the event was received by SCM |
| Event Time | Date and time when the action occurred |
| Event Name | The type of operation performed: `create`, `update`, or `delete` |
| Event Details | The request body of the operation. Sensitive values, such as API keys, are masked |
| Event Result | Outcome of the request, based on the HTTP status code: `Success` (2xx), `Failure` (4xx), or `Error` (5xx) |
| Event Description | The HTTP method and URI of the request |
| Event Category | The type of resource affected, such as API keys, integrations, or workspaces |
| Source User | The ID of the user who performed the action |
| Client IP | IP address from which the request originated |
| Request ID | Unique identifier of the request |
