The Prisma AIRS AI Gateway provides a robust and secure gateway to facilitate the integration of various Large Language Models (LLMs) into your applications, including [OVHcloud AI Endpoints](https://www.ovhcloud.com/en/public-cloud/ai-endpoints/).

With the AI Gateway, you can take advantage of features like fast AI gateway access, observability, prompt management, and more, all while ensuring the secure management of your LLM API keys through [Model Catalog](/aigw/product/model-catalog).
<Note>
Provider Slug. `ovhcloud`
</Note>
## Using OVHcloud AI Endpoints with the AI Gateway

The AI Gateway provides a consistent API to interact with models from various providers. To integrate AI Endpoints with the AI Gateway:

### 1\. Install the OpenAI SDK

Add the OpenAI SDK to your application to interact with AI Endpoints's API through the AI Gateway.

<Tabs>
    <Tab title="NodeJS">
        ```sh
 npm install openai --save
        ```
    </Tab>
    <Tab title="Python">
        ```sh
 pip install openai
        ```
    </Tab>

  </Tabs>

### 2\. Initialize the AI Gateway with Your AI Provider

Navigate to the [OVHcloud control panel](https://ovh.com/manager), in `Public Cloud` > `AI & Machine Learning` > AI Endpoints > API key. Add it to [Model Catalog](https://stratacloudmanager.paloaltonetworks.com/) to get your AI Provider slug.


### **3\. Invoke Chat Completions with** AI Endpoints

Use the AI Gateway instance to send requests to AI Endpoints.


## Managing OVHcloud AI Endpoints Prompts

You can manage all prompts to AI Endpoints in the Prompt Library. All the current models of AI Endpoints are supported and you can easily start testing different prompts.

Once you're ready with your prompt, call the `POST /v1/prompts/{promptId}/completions` endpoint to use it in your application.

### AI Endpoints Tool Calling
Tool calling feature lets models trigger external tools based on conversation context. You define available functions, the model chooses when to use them, and your application executes them and returns results.

The AI Gateway supports AI Endpoints Tool Calling and makes it interoperable across multiple providers. With AI Gateway Prompts, you can templatize various your prompts & tool schemas as well.

```curl Get Weather Tool

       "messages": [

         "type": "function",

           "description": "Get the current weather",

             "properties": {
               "location": {"type": "string", "description": "City and state"},
               "unit": {"type": "string", "enum": ["celsius", "fahrenheit"]}
             },
             "required": ["location"]
           }
         }
       }],
       "tool_choice": "auto"
     }'
```

### AI Endpoints Speech to Text (Whisper)

OpenAI's Audio API converts speech to text using the Whisper model. It offers transcription in the original language and translation to English, supporting multiple file formats and languages with high accuracy.

<CodeGroup>


```curl REST
# Transcription
curl -X POST "https://aigw.portkey.ai/v1/audio/transcriptions" \
     -H "Authorization: Bearer YOUR_PORTKEY_API_KEY" \
     -H "Content-Type: multipart/form-data" \
     -F "file=@/path/to/file.mp3" \
     -F "model=whisper-large-v3"

# Translation
curl -X POST "https://aigw.portkey.ai/v1/audio/translations" \
     -H "Authorization: Bearer YOUR_PORTKEY_API_KEY" \
     -H "Content-Type: multipart/form-data" \
     -F "file=@/path/to/file.mp3" \
     -F "model=whisper-large-v3"
```
</CodeGroup>
