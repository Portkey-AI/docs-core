Route [Claude Code](https://code.claude.com/docs/en/overview) through Anthropic's Direct API via the AI Gateway. Get full observability, cost tracking, and budget controls. Also supports Max plan and Anthropic OAuth.

See [Claude Code overview](/aigw/integrations/libraries/claude-code) for why platform teams use the AI Gateway.

<Note>
**Important:** Always use the latest version of Claude Code. Older versions may not work with the AI Gateway's gateway.
</Note>

## Quick Start

<Steps>
<Step title="Add Anthropic Provider in the AI Gateway">

Go to [AI Providers](https://stratacloudmanager.paloaltonetworks.com/) → **Add Provider** → Select **Anthropic**.

Enter your Anthropic API key and create a slug like `anthropic-prod`.

</Step>

<Step title="Get Your AI Gateway API Key">

Go to [API Keys](https://stratacloudmanager.paloaltonetworks.com/) → Generate a new key.

</Step>

<Step title="Configure Claude Code">

Edit `~/.claude/settings.json` (user-level) or `.claude/settings.json` (project-level):

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://aigw.portkey.ai",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_PORTKEY_API_KEY",
    "ANTHROPIC_CUSTOM_HEADERS": "Authorization: Bearer YOUR_PORTKEY_API_KEY\nx-portkey-provider: @anthropic-prod",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-sonnet-4-20250514",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-4-20250514",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-haiku-4-20250514"
  },
  "model": "claude-sonnet-4-20250514"
}
```

Replace:
- `YOUR_PORTKEY_API_KEY` with your AI Gateway API key
- `@anthropic-prod` with your provider slug
</Step>
</Steps>

That's it! All Claude Code requests now route through Anthropic via the AI Gateway. Monitor usage in the [Strata Cloud Manager](https://stratacloudmanager.paloaltonetworks.com/).

## Max Plan / Anthropic OAuth (Enterprise)

For Max plan or Anthropic OAuth users:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://aigw.portkey.ai",
    "ANTHROPIC_CUSTOM_HEADERS": "Authorization: Bearer YOUR_PORTKEY_API_KEY\nx-portkey-provider:anthropic"
  }
}
```

<Info>
**Cost tracking:** With Max plan, costs show as $0 in the AI Gateway since Anthropic bills directly. The AI Gateway still tracks request counts, latency, tokens, and traces.
</Info>

## Forward Headers (Required for Some Features)

Some Claude Code features require the `anthropic-beta` header. Configure this in a [AI Gateway Config](/aigw/product/ai-gateway/configs):

<Steps>
<Step title="Create a Config">

Go to [Configs](https://stratacloudmanager.paloaltonetworks.com/) → **Create Config**:

```json
{
  "provider": "@anthropic-prod",
  "forward_headers": ["anthropic-beta"]
}
```

Save and copy the Config ID.
</Step>

<Step title="Update Claude Code Settings">

Add the config to your settings:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://aigw.portkey.ai",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_PORTKEY_API_KEY",
    "ANTHROPIC_CUSTOM_HEADERS": "Authorization: Bearer YOUR_PORTKEY_API_KEY\nx-portkey-config: YOUR_CONFIG_ID"
  }
}
```
</Step>
</Steps>

## Trace Requests

Add trace IDs to group and debug requests in Strata Cloud Manager:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://aigw.portkey.ai",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_PORTKEY_API_KEY",
    "ANTHROPIC_CUSTOM_HEADERS": "Authorization: Bearer YOUR_PORTKEY_API_KEY\nx-portkey-provider: @anthropic-prod\nx-portkey-trace-id: claude-code-session-123"
  }
}
```

Use trace IDs to:
- Group all requests from a coding session
- Debug issues by filtering logs
- Track usage per project or task

## Advanced Configuration

### Fallbacks

Route to backup providers when Anthropic fails. Create a config with fallback targets:

```json
{
  "strategy": { "mode": "fallback" },
  "targets": [
    { "provider": "@anthropic-prod" },
    { "provider": "@bedrock-prod" },
    { "provider": "@vertex-prod" }
  ],
  "forward_headers": ["anthropic-beta"]
}
```

### Load Balancing

Distribute requests across multiple API keys or providers:

```json
{
  "strategy": { "mode": "loadbalance" },
  "targets": [
    { "provider": "@anthropic-key-1", "weight": 0.5 },
    { "provider": "@anthropic-key-2", "weight": 0.5 }
  ],
  "forward_headers": ["anthropic-beta"]
}
```

### Caching

Reduce costs and latency for repeated queries:

```json
{
  "provider": "@anthropic-prod",
  "cache": { "mode": "simple" },
  "forward_headers": ["anthropic-beta"]
}
```

### Retries

Automatically retry failed requests:

```json
{
  "provider": "@anthropic-prod",
  "retry": { "attempts": 3, "on_status_codes": [429, 500, 502, 503] },
  "forward_headers": ["anthropic-beta"]
}
```

## Budget Limits

Set spending controls at the provider level:

1. Go to [Model Catalog](https://stratacloudmanager.paloaltonetworks.com/) → Select your Anthropic provider
2. Click **Set Now**
3. Configure:
   - **Cost limit**: Maximum spend (e.g., $500/month)
   - **Token limit**: Maximum tokens (e.g., 10M tokens/week)
   - **Rate limit**: Requests per minute/hour

Budget limits prevent runaway costs from agentic coding sessions.

## Troubleshooting

### Lightning Symbol (⚡) in Logs

**Cause:** Requests are going through as passthrough, meaning the AI Gateway isn't handling them properly.

**Fix:**
1. Remove `/v1` from the base URL — use `https://aigw.portkey.ai`
2. Ensure `x-portkey-provider` or `x-portkey-config` is set in headers
3. Verify your AI Gateway API key is correct

### Claude Code Version Issues

**Cause:** Older versions of Claude Code may not be compatible.

**Fix:** Update to the latest version:
```bash
claude update
```

Or reinstall:
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
