GitHub Copilot is an AI pair programmer. Route Copilot through the AI Gateway to get:

- **3,000+ LLMs** — Use any model, not just Copilot's defaults
- **Observability** — Track costs, tokens, latency
- **Governance** — Budget limits, rate limits, RBAC
- **Guardrails** — PII detection, content filtering

<Note>
**Experimental integration.** Only GitHub Copilot Chat works with the AI Gateway. Advanced Copilot features are not available yet.
</Note>

## 1. Setup the AI Gateway

<Steps>
<Step title="Add Provider">
Go to [Model Catalog](https://stratacloudmanager.paloaltonetworks.com/) → **Add Provider**.

</Step>

<Step title="Configure Credentials">
Select your provider (OpenAI, Anthropic, etc.), enter your API key, and create a slug like `openai-prod`.

<Frame>
<img src="/images/product/model-catalog/create-provider-page.png" width="500"/>
</Frame>

</Step>

<Step title="Copy Model Slug">
Go to [Model Catalog](https://stratacloudmanager.paloaltonetworks.com/) → **Models** → Copy the slug (e.g., `@openai-prod/gpt-4o`).

<Frame>
<img src="/images/product/model-catalog/model-integration-model-box.png" width="500"/>
</Frame>

</Step>

<Step title="Create Config">
Go to [Configs](https://stratacloudmanager.paloaltonetworks.com/) and create:

```json
{
  "override_params": {
    "model": "@openai-prod/gpt-4o"
  }
}
```

Save and note the Config ID.

</Step>

<Step title="Get AI Gateway API Key">
Go to [API Keys](https://stratacloudmanager.paloaltonetworks.com/) → Create new key → Attach your config → Save.

<Frame>
<img src="/images/integrations/api-key.png" width="300"/>
</Frame>

</Step>
</Steps>

## 2. Configure GitHub Copilot

<Steps>
<Step title="Open Manage Models">
In Copilot chat, click the **model dropdown** → **Manage Models**.

</Step>

<Step title="Add Custom Model via Azure">
1. Select **Azure** → Click **gear icon** → **Configure models** → **Add a new model**
2. Fill in:
   - **Identifier**: `portkey-model`
   - **Display name**: `Custom AI Gateway Model`
   - **API endpoint URL**: `https://aigw.portkey.ai/v1/chat/completions`
   - **Capabilities**: Enable Tools, Vision, Thinking as needed
   - **Token limits**: Set based on your model

</Step>

<Step title="Add API Key">
1. From **Manage Models** → Select **Azure** → Select your model
2. In **API Keys**, paste your **AI Gateway API Key**
3. Save

</Step>
</Steps>

Done! Your Copilot requests now route through the AI Gateway with observability and controls.
