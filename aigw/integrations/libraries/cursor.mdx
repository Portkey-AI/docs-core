[Cursor](https://cursor.sh) is an AI-first code editor. Add the AI Gateway to get:

- **1600\+ LLMs** — Not just OpenAI & Anthropic
- **Observability** — Track costs, tokens, latency for every request
- **Governance** — Budget limits, rate limits, RBAC
- **Guardrails** — PII detection, content filtering

<Note>
  When using the AI Gateway, Cursor-specific features (autocomplete, Apply from Chat, inline refactoring) require Cursor Pro/Enterprise plans.
</Note>

<Note>
  For enterprise governance, see [Enterprise Governance](#enterprise-governance).
</Note>

## 1. Setup

<Steps>
  <Step title="Add Provider">
    Go to [Model Catalog](https://stratacloudmanager.paloaltonetworks.com/) → **Add Provider**.

  </Step>
  <Step title="Configure Credentials">
    Select your provider (OpenAI, Anthropic, etc.), enter your API key, and create a slug like `openai-prod`.

  </Step>
  <Step title="Create Config">
    Go to [Configs](https://stratacloudmanager.paloaltonetworks.com/) and create:

    ```json
    {
      "override_params": {
        "model": "@openai-prod/gpt-4"
      }
    }
    ```

    <Note>
      Add `"cache_control": {"type": "ephemeral"}` inside `override_params` to your config to enable caching and optimise costs for Anthropic models.
    </Note>

    Save and note the Config ID.
  </Step>
  <Step title="Get AI Gateway API Key">
    Go to [API Keys](https://stratacloudmanager.paloaltonetworks.com/) → Create new key → Attach your config → Save.
  </Step>
</Steps>

## 2. Configure Cursor

1. Open **Cursor → Settings → Cursor Settings → Models**
2. Scroll to **API Keys** section
3. Enable **OpenAI API Key** toggle and enter your **AI Gateway API Key**
4. Enable **Override OpenAI Base URL** and enter: `https://aigw.portkey.ai/v1`

5. Under **Models** on the same page, create a custom model named `portkey_model` and ensure it is **enabled** (toggle on).

6. In **Chat**, open the model picker and select that custom model so every message goes through the AI Gateway.

<Note>
  **Logs and analytics:** Creating the custom model under **Models** is not enough on its own—you must also select it in **Chat**. Otherwise Cursor may send traffic on a built-in model id and those calls may not appear in Strata Cloud Manager.

  **Custom model name:** Do not use a name that includes or resembles a real provider model identifier in any form Cursor might recognize (different casing, `gpt_4o` vs `gpt-4o`, substrings such as `gpt-4` inside a longer string, and so on). For example, avoid `gpt-4o`, `sample-gpt-4o`, or similar. Prefer a neutral label like `portkey_model` or `acme-ai-gateway`.
</Note>

Done! Monitor usage in the [Strata Cloud Manager](https://stratacloudmanager.paloaltonetworks.com/).
