## Gateway

### Messages API to Responses API Routing

Route Messages API requests to Responses API models—like OpenAI's Codex—without changing your client code. Requests and responses are transformed automatically in both directions.

Learn more: [Responses API](https://portkey.ai/docs/api-reference/inference-api/responses/responses)

## Guardrails

### Prisma AIRS: Agentic Client Support

False positives drop significantly for agentic clients like Claude Code, Cursor, and Cline. **`strip_scaffolding`** removes agent-harness content—system prompts, MCP tool instructions—before scanning, so Prisma AIRS inspects actual user content. **`scan_scope`** gives you control over which messages get scanned.

Learn more: [Prisma AIRS](https://portkey.ai/docs/integrations/guardrails/palo-alto-panw-prisma)

### Guardrails: Soft Deny

Guardrail denials no longer crash agentic sessions. With **`soft_deny_200`**, a denial comes back as HTTP 200 formatted as a chat completion response—so clients like Claude Code that treat 4xx as fatal errors keep running and see the denial as a model response.

Learn more: [Guardrails](https://portkey.ai/docs/product/guardrails)
